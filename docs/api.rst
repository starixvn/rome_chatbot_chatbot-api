change_display_name
-------------------

To change the display name of business accounts.

Name: **bot/change_display_name/{{account_id}}**

Method: ``PUT``

* Header::

	{
		Content-Type : ​text/plan
		Authorization : Bearer base64(api key)
	}

*  Input: JSON object::

	{
		"display_name": String
	}
	
*  Output: JSON object::

	{
		"status": int,
		"message": String
	}
	
* Status:

	+------------+-----------------------------------------------------------------+
	| Code       | Description                                                     |
