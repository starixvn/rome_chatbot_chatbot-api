Document Purpose
*****************

This document provides a description of our technical solution to build up a more secure and more convenient way for SMA to receive up-to-date significant information from the Alpha site via Letstalk channel.

The main purpose of this document is to **facilitate technical understanding and thorough communication between the Alpha team and Letstalk team** during integration phase.

The document also intends to capture and express the vital architecture and design decisions that have been made for this project.
