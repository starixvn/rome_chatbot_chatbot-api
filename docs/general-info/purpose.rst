*****************
Document Purpose
*****************

This document provides a description of the technical solution to build up a more secure and more convenient way for SMA to receive up-to-date significant information from the Alpha site via Letstalk channel.

The main purpose of this document is to **facilitate technical understanding and communication between the Alpha team and Letstalk team** during the project integration phase.

The document also intends to capture and express the significant architecture and design decisions that have been made for this project.
