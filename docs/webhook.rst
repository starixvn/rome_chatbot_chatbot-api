Webhook Event
=============

Common properties
-----------------

* Desription

	+--------------+-----------+---------------------------------------------------------+
	|Property      |Type       |Description                                              |
	+==============+===========+=========================================================+
	|``type``      |String     |Identifier for the type of event.                        |
	+--------------+-----------+---------------------------------------------------------+
	|``timestamp`` |Number     |Time of the event in milliseconds.                       |
	+--------------+-----------+---------------------------------------------------------+
	|``source``    |Object     |Source user object with information about the source of  |
	|              |           |the event.                                               |
	+--------------+-----------+---------------------------------------------------------+
	
* Source User

	+--------------+-----------+---------------------------------------------------------+
	|Property      |Type       |Description                                              |
	+==============+===========+=========================================================+
	|``type``      |String     |user                                                     |
	+--------------+-----------+---------------------------------------------------------+
	|``user_id``   |String     |Letstalk ID of the source user.                          |
	+--------------+-----------+---------------------------------------------------------+

Health check Event
------------------

* Description

	+--------------+-----------+---------------------------------------------------------+
	|Property      |Type       |Description                                              |
	+==============+===========+=========================================================+
	|``type``      |String     |health_check                                             |
	+--------------+-----------+---------------------------------------------------------+

* Example::

	{
		"type": "health_check",
		"timestamp": 1527151205790
	}

Message Event
-------------

* Desription

	+--------------+-----------+---------------------------------------------------------+
	|Property      |Type       |Description                                              |
	+==============+===========+=========================================================+
	|``type``      |String     |message                                                  |
	+--------------+-----------+---------------------------------------------------------+
	|``payload``   |String     |message payload. This will be an encrypted JSON String.  |
	+--------------+-----------+---------------------------------------------------------+
	
* Example::

	{
		"type": "message",
		"timestamp": 1527151205790,
		"source": {
			"type": "user",
			"user_id": "jimmy.chen"
		},
		"payload": String
	}
