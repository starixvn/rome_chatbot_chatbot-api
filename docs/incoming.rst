Incoming Payload
================

Common properties
-----------------

* Description

	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``type``            |String     |Identifier for the type of msg.                          |
	|                    |           | - 0: Text, 2: Image, 3: Voice, 6: Video, 7: GIF, 8: File|
	+--------------------+-----------+---------------------------------------------------------+
	|``user_id``         |String     |Sender ID                                                |
	+--------------------+-----------+---------------------------------------------------------+
	|``receiver``        |String     |Receiver ID                                              |
	+--------------------+-----------+---------------------------------------------------------+
	|``id``              |Number     |Message ID                                               |
	+--------------------+-----------+---------------------------------------------------------+
	|``time``            |Number     |Time of the Message in milliseconds.                     |
	+--------------------+-----------+---------------------------------------------------------+
	|``send_time``       |Number     |Time of the Message send in milliseconds.                |
	+--------------------+-----------+---------------------------------------------------------+
	|``duedate``         |Number     |Time of the Message due date in milliseconds.            |
	+--------------------+-----------+---------------------------------------------------------+
	|``from``            |Number     |From Device                                              |
	|                    |           | - 0: Mobile, 1:Desktop                                  |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_content``    |String     |Encrypted text.                                          |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_content_key``|String     |The plain text to SHA1                                   |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_id``         |Number     |AES key id.                                              |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_type``       |Number     |Encryption mode                                          |
	|                    |           | - 5: AES                                                |
	+--------------------+-----------+---------------------------------------------------------+

hash_content properties
-----------------------

* Text Type

	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``msg``             |String     |Text content                                             |
	+--------------------+-----------+---------------------------------------------------------+
	|``quote``           |Object     |Quote info                                               |
	+--------------------+-----------+---------------------------------------------------------+
	
	Quote Object
	
	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``display_name``    |String     |User display name. Found in the quote object.            |
	+--------------------+-----------+---------------------------------------------------------+
	|``annount_name``    |String     |User Letstalk ID. Found in the quote object.             |
	+--------------------+-----------+---------------------------------------------------------+
	|``content``         |String     |Text content. Found in the quote object.                 |
	+--------------------+-----------+---------------------------------------------------------+
	
* Image Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``preview_image_url`` |String     |Preview image URL                                      |
	+----------------------+-----------+-------------------------------------------------------+
	|``original_image_url``|String     |Image URL                                              |
	+----------------------+-----------+-------------------------------------------------------+
	|``zip_password``      |String     |Zip file password                                      |
	+----------------------+-----------+-------------------------------------------------------+
	
* Voice Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``voice_url``         |String     |URL of voice file                                      |
	+----------------------+-----------+-------------------------------------------------------+
	|``voice_duration``    |Number     |Length of voice file. (milliseconds)                   |
	+----------------------+-----------+-------------------------------------------------------+
	|``zip_password``      |String     |Zip file password                                      |
	+----------------------+-----------+-------------------------------------------------------+
	
* Video Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``preview_image_url`` |String     |URL of preview image                                   |
	+----------------------+-----------+-------------------------------------------------------+
	|``video_url``         |String     |URL of video file                                      |
	+----------------------+-----------+-------------------------------------------------------+
	|``video_duration``    |Number     |Length of video file. (milliseconds)                   |
	+----------------------+-----------+-------------------------------------------------------+
	|``video_size``        |Number     |Size of video file. (bytes)                            |
	+----------------------+-----------+-------------------------------------------------------+
	|``zip_password``      |String     |Zip file password                                      |
	+----------------------+-----------+-------------------------------------------------------+
	
* GIF Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``gif_key``           |String     |Giphy key. (https://giphy.com/)                        |
	+----------------------+-----------+-------------------------------------------------------+
	
* File Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``file_name``         |String     |File name                                              |
	+----------------------+-----------+-------------------------------------------------------+
	|``file_url``          |String     |URL of file                                            |
	+----------------------+-----------+-------------------------------------------------------+
	|``file_size``         |Number     |Size of file. (bytes)                                  |
	+----------------------+-----------+-------------------------------------------------------+
	|``zip_password``      |String     |Zip file password                                      |
	+----------------------+-----------+-------------------------------------------------------+
