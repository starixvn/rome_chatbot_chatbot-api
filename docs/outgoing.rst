Outgoing Payload
================

Common properties
-----------------

* Description

	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``type``            |String     |Identifier for the type of msg.                          |
	|                    |           | - 60: Text, 61: Image, 62: Image map                    |
	+--------------------+-----------+---------------------------------------------------------+
	|``user_id``         |String     |Sender ID                                                |
	+--------------------+-----------+---------------------------------------------------------+
	|``receiver``        |String     |Receiver ID                                              |
	+--------------------+-----------+---------------------------------------------------------+
	|``id``              |Number     |Message ID                                               |
	+--------------------+-----------+---------------------------------------------------------+
	|``time``            |Number     |Time of the Message in milliseconds.                     |
	+--------------------+-----------+---------------------------------------------------------+
	|``send_time``       |Number     |Time of the Message send in milliseconds.                |
	+--------------------+-----------+---------------------------------------------------------+
	|``duedate``         |Number     |Time of the Message due date in milliseconds.            |
	+--------------------+-----------+---------------------------------------------------------+
	|``from``            |Number     |From Device                                              |
	|                    |           | - 2: Business Account                                   |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_content``    |String     |Encrypted text.                                          |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_content_key``|String     |The plain text to SHA1                                   |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_id``         |Number     |AES key id.                                              |
	+--------------------+-----------+---------------------------------------------------------+
	|``hash_type``       |Number     |Encryption mode                                          |
	|                    |           | - 5: AES                                                |
	+--------------------+-----------+---------------------------------------------------------+
	
hash_content properties
-----------------------

* Text Type

	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``msg``             |String     |Text content                                             |
	+--------------------+-----------+---------------------------------------------------------+

* Image Type
	
	+----------------------+-----------+-------------------------------------------------------+
	|Property              |Type       |Description                                            |
	+======================+===========+=======================================================+
	|``original_image_url``|String     |Original image URL                                     |
	|                      |           | - **HTTPS** (Required)                                |
	|                      |           | - JPEG                                                |
	|                      |           | - MAX: 1024 x 1024                                    |
	|                      |           | - MAX: 1MB                                            |
	+----------------------+-----------+-------------------------------------------------------+
	|``preview_image_url`` |String     |Preview image URL                                      |
	|                      |           | - **HTTPS** (Required)                                |
	|                      |           | - JPEG                                                |
	|                      |           | - MAX: 640 x 640                                      |
	|                      |           | - MAX: 1MB                                            |
	+----------------------+-----------+-------------------------------------------------------+
	
* Image Map Type

	+----------------------+-------------+-----------------------------------------------------+
	|Property              |Type         |Description                                          |
	+======================+=============+=====================================================+
	|``base_url``          |String       |Image URL                                            |
	|                      |             | - **HTTPS** (Required)                              |
	|                      |             | - JPEG or PNG                                       |
	|                      |             | - Image width: 240px, 300px, 460px, 700px, 1040px   |
	|                      |             | - MAX: 1MB                                          |
	+----------------------+-------------+-----------------------------------------------------+
	|``alt_text``          |String       |Alternative text                                     |
	+----------------------+-------------+-----------------------------------------------------+
	|``base_size_width``   |Number       |Width of base image (set to 1040px)                  |
	+----------------------+-------------+-----------------------------------------------------+
	|``base_size_height``  |Number       |Height of base image (set to the height that         |
	|                      |             |corresponds to a width of 1040px)                    |
	+----------------------+-------------+-----------------------------------------------------+
	|``actions``           |Array of     |Action when tapped, Max:5                            |
	|                      |Action object|                                                     |
	+----------------------+-------------+-----------------------------------------------------+

* Action object
	URI Action type
	
	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``type``            |String     |uri                                                      |
	+--------------------+-----------+---------------------------------------------------------+
	|``link_uri``        |String     |Web page URL                                             |
	+--------------------+-----------+---------------------------------------------------------+
	|``area``            |Area object|Defined tappable area.                                   |
	+--------------------+-----------+---------------------------------------------------------+
	
	Message Action Type
		
	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``type``            |String     |message                                                  |
	+--------------------+-----------+---------------------------------------------------------+
	|``text``            |String     |Message to send                                          |
	|                    |           | - MAX: 400 characters                                   |
	+--------------------+-----------+---------------------------------------------------------+
	|``area``            |Area object|Defined tappable area.                                   |
	+--------------------+-----------+---------------------------------------------------------+
	
* Area object

	+--------------------+-----------+---------------------------------------------------------+
	|Property            |Type       |Description                                              |
	+====================+===========+=========================================================+
	|``x``               |Number     |Horizontal position relative to the top-left corner of   |
	|                    |           |the area                                                 |
	+--------------------+-----------+---------------------------------------------------------+
	|``y``               |Number     |Vertical position relative to the top-left corner of     |
	|                    |           |the area                                                 |
	+--------------------+-----------+---------------------------------------------------------+
	|``width``           |Number     |Width of the tappable area                               |
	+--------------------+-----------+---------------------------------------------------------+
	|``height``          |Number     |Height of the tappable area                              |
	+--------------------+-----------+---------------------------------------------------------+
